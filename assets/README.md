# Aset visual

`ceremony-landscape.webp` adalah ilustrasi alutsista untuk latar dekoratif portal HUT ke-80 Arhanud. Dibuat menggunakan built-in image_gen (skill imagegen), kemudian dikompresi ke WebP 1659 × 948, kualitas 85. Lambang Arhanud menggunakan `logo.png` asli dari proyek.

## Prompt final

Use case: stylized-concept. Asset type: cinematic background artwork for a premium Indonesian Army air-defense anniversary ceremony website, not a UI mockup. Create a very wide landscape 1792x1024 composition: a grounded realistic silhouette of a modern olive-drab towed twin-barrel anti-aircraft artillery piece, viewed from a low side/rear angle, pointing diagonally up toward right, positioned in the RIGHT THIRD of the frame on a dark ridge, with misty layered tropical mountain silhouettes behind. Restrained editorial defense photography aesthetic, atmospheric early morning fog, dark forest green charcoal tones #080B09 #101410 #1F3828, subtle warm brass sunlight near horizon behind cannon, no combat, no firing, no people. The LEFT HALF must be quiet empty very dark green haze with no objects to overlay large white website typography. Upper half lots of shadowy sky. Elegant, peaceful, dignified, premium ceremony, real-world materials, soft film grain. No neon, no game style, no sci-fi, no dramatic orange explosions, no logos, no text, no badges, no lettering, no watermark. Detailed yet understated gun silhouette, slightly silhouetted dark tone but still readable.

## Font

Font diambil dari Google Fonts dan disimpan lokal agar halaman tidak memerlukan layanan font eksternal:

- Barlow Condensed Semibold (600): https://fonts.google.com/specimen/Barlow+Condensed
- Manrope variable (200–800): https://fonts.google.com/specimen/Manrope

Lisensi SIL Open Font License masing-masing ada di folder `fonts/`. Berkas font memakai subset Latin.
